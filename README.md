# Iced Playground

A small desktop app for learning [iced](https://github.com/iced-rs/iced), a GUI library for Rust.

## Requirements

- Rust 1.99 or newer

## Building

Clone the repository:

```bash
git clone https://github.com/naxemis/iced-playground.git
cd iced-playground
```

Build the project:

```bash
cargo build
```

## Running

Run the application with:

```bash
cargo run
```

## Testing

Run all tests:

```bash
cargo test
```
